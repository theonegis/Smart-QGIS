# 测试范围与当前证据

开发回归使用：

```bash
uv sync --locked
uv run ruff check src tests
uv run pytest -q
```

测试覆盖工具参数、任务状态与恢复，以及在有 QGIS 环境时的真实 Processing、样式、布局和导出。没有安装 QGIS 的机器会跳过相应集成测试；自动测试通过不等于所有 provider、算法和操作系统都已验收。

## GIS 与制图集成检查

在安装了 QGIS 的测试环境中，集成检查实际运行 Processing、样式、布局、地图导出和工程重开。验收不只检查工具返回值，还检查输出可打开性、CRS，以及地图要求的基本元素。具体算法的科学正确性应使用独立于 MCP 返回值的任务参考进行验证。

## 复现注意

- 每个独立测试使用新的临时状态和输出目录；恢复测试则必须继续原任务并保留失败记录。
- `COMPLETED` 或存在输出文件都不是科学正确性的充分条件；算法测试应有与 MCP 契约分离的独立参考，地图测试应检查实际渲染结果。
- QGIS provider 与参数受安装环境影响。尤其不能把一台机器的 GRASS/GDAL 算法 ID、枚举值或表达式语法当作所有机器的默认值。
